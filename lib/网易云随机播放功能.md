# 随机动漫音乐 API 文档

## 一、接口概述

本接口基于网易云音乐版权资源，提供随机动漫音乐获取能力，支持「日漫歌曲」「日漫纯音乐」两种分类，可直接返回歌曲元数据，也支持跳转至音源播放地址，适合嵌入播放器、随机歌单等场景。

## 二、基础信息

表格

| 项 | 说明 |
| --- | --- |
| 请求地址 | `https://api.paugram.com/acgm/` |
| 请求方式 | `GET` |
| 返回格式 | `application/json` |
| 数据来源 | 网易云音乐 |
| 调用频率 | 无公开限制，禁止滥用 |

## 三、请求参数

所有参数均通过 Query 方式传递，均为可选参数。

表格

| 参数名 | 是否必填 | 类型 | 可选值 | 默认值 | 描述 |
| --- | --- | --- | --- | --- | --- |
| list | 否 | integer | `1` / `2` | 随机全品类 | 音乐分类：1 = 日漫歌曲2 = 日漫纯音乐 |
| play | 否 | boolean | `true` | 关闭 | 是否直接跳转至音源播放地址：传 `true` 时，请求后会直接 302 跳转到歌曲播放链接；不传或传其他值时，返回 JSON 格式的歌曲信息 |

## 四、响应参数

当未启用 `play` 跳转时，接口返回 JSON 格式的歌曲详情，字段如下：

表格

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| id | number | 网易云音乐歌曲 ID |
| title | string | 音乐名称 |
| artist | string | 艺术家 / 作曲者 |
| album | string | 所属专辑名称 |
| cover | string | 专辑封面图片地址（HTTPS，默认 250×250 尺寸） |
| link | string | 歌曲音源外链地址（HTTPS） |
| lyric | string | 歌词文本，带时间轴格式；纯音乐返回「纯音乐，请欣赏」 |
| sub_lyric | string | 翻译 / 副歌词，无内容时为空字符串 |
| cached | boolean | 该歌曲是否已被服务端缓存 |

## 五、请求示例

### 1. 基础调用：获取一首随机动漫音乐

```
https://api.paugram.com/acgm/
```

### 2. 指定分类：获取随机日漫纯音乐

```
https://api.paugram.com/acgm/?list=2
```

### 3. 直接跳转播放

请求后会自动跳转到音源地址，可直接作为音频源使用：

```
https://api.paugram.com/acgm/?list=1&play=true
```

### 4. 嵌入 HTML 播放器

```
<audio src="https://api.paugram.com/acgm/?play=true" controls>
```

## 七、错误说明

### 异常返回

当参数格式错误、请求非法时，接口返回文本错误提示：

```
系统内部异常，请稍后重试
```

### 常见错误原因

1. `play` 参数格式错误：例如多写了引号、传了非 `true` 的非法值
2. `list` 参数值不在 `1/2` 范围内
3. 服务端临时故障或网易云音源接口异常

## 八、注意事项

1. **版权声明**：所有音乐版权归网易云音乐所有，禁止将本接口用于商业违规用途，违规滥用自行承担责任。
2. **去重机制**：接口会通过 Cookie 记录访问信息，降低连续随机到同一首歌的概率，调用即视为同意使用 Cookie。
3. **播放可用性**：部分歌曲可能因版权限制失效，出现无法播放属于正常情况，重新调用即可获取新曲目。
4. **跳转规范**：启用 `play=true` 时为 302 重定向，请勿在异步接口请求中使用该模式，适合直接作为音频 `src` 或浏览器地址访问。
